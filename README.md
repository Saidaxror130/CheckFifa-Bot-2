# ПВЗ Монитор Bot

Telegram-бот для мониторинга статусов ПВЗ в Google Таблице. Проверяет таблицу каждые 5 часов и уведомляет о новых событиях по вашим ПВЗ.

## ✨ Особенности

- 🔄 Автоматическая проверка каждые 5 часов
- 🚀 Retry механизм с экспоненциальной задержкой при ошибках сети
- 🗑 Автоматическая ротация кеша (удаление записей старше 3 дней)
- 🔒 Система whitelist с owner-only командами
- ⚡ Улучшенная обработка ошибок

## ⚙️ Переменные окружения (Railway Variables)

| Переменная       | Описание                                             | Пример                      |
|-----------------|------------------------------------------------------|-----------------------------|
| `BOT_TOKEN`     | Токен Telegram-бота от @BotFather                   | `123456:ABC-DEF...`         |
| `SPREADSHEET_ID`| ID таблицы Google Sheets (часть после `/d/` в URL)  | `1IlevSaex23SAxAhfKFV0H9...`|
| `CHAT_ID`       | Ваш Telegram ID (уже вшит: 6061065577)              | `6061065577`                |
| `OWNER_ID`      | ID владельца бота (опционально, по умолчанию 6061065577) | `6061065577`        |
| `CHECK_INTERVAL_HOURS` | Интервал проверки в часах (опционально, по умолчанию 5) | `3`              |

## 🚀 Деплой на Railway

1. Создайте репозиторий на GitHub и залейте файлы:

```bash
git init
git add .
git commit -m "init pvz bot"
git remote add origin https://github.com/YOUR_USERNAME/pvz-bot.git
git push -u origin main
```

2. В Railway:
   - New Project → Deploy from GitHub repo
   - Выберите ваш репозиторий
   - В разделе **Variables** добавьте:
     - `BOT_TOKEN`
     - `SPREADSHEET_ID`
     - `CHAT_ID` (опционально, уже = 6061065577)

3. Railway автоматически установит зависимости и запустит `python bot.py`

## 📋 Команды бота

### Для всех пользователей (whitelist):

| Команда        | Описание                                    |
|---------------|---------------------------------------------|
| `/start`      | Приветствие и список команд                 |
| `/refresh`    | Принудительная проверка таблицы             |

| `/clear_cache`| Полная очистка кеша                         |

| Команда        | Описание                                    |
|---------------|---------------------------------------------|

| `/interval`   | Настройка интервала проверки (1-24 часа)    |

## 🔔 Уведомления

Бот отправляет уведомление когда:
- 🚚 **Ожидает приёмки** — товар прибыл на ПВЗ, ещё не принят
- 📦 **Принят** — администратор ПВЗ принял товар  
- ✅ **Выдан** — клиент забрал заказ

Повторные уведомления не приходят — каждая строка кешируется по ключу
`order_id|pvz|статус_приёмки|статус_выдачи`. При смене статуса строка считается новой.

Кеш автоматически очищается от записей старше 3 дней для экономии памяти.

## 🌐 Google Sheets — важно!

Таблица должна быть **открыта для просмотра по ссылке** (Файл → Поделиться → Доступ по ссылке → Просматривать).

Бот читает лист **"Лист1"**. Если лист называется иначе — измените `SHEET_NAME` в `sheets.py`.

## 🛠 Технические улучшения

- **Retry механизм**: 3 попытки с экспоненциальной задержкой (1s, 2s, 4s) при ошибках сети
- **Ротация кеша**: автоматическое удаление записей старше 3 дней
- **Обработка ошибок**: детальные сообщения об ошибках с подсказками для пользователя
- **Права доступа**: /refresh и /clear_cache доступны всем в whitelist, /admins и /interval только владельцу
- **Настраиваемый интервал**: владелец может изменить интервал проверки от 1 до 24 часов через команду /interval
